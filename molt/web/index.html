WHY MOLT EXISTS

Teach once. Test against truth. Reuse without guessing.

The model is a compiler, not the runtime
01

What Gemma sees

Your task, column names, type counts, and masked examples. Gemma proposes a constrained JSON recipe; it does not keep a permanent memory of your business.

02

What Molt stores

The recipe version, its verification results, approval decision, schema contract, and audit trail are stored in SQLite for this workspace.

03

What changes on a new file

Molt compares the file to the approved contract. Compatible files run deterministically with zero model calls. Missing columns, unexpected values, or type drift stop the run.

04

What a human approves

A candidate stays inactive until independent fixtures and invariants pass. Approval is a deliberate click; failed candidates cannot replace the active recipe.
